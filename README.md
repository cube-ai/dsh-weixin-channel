# DSH微信频道

`@cubeai/dsh-weixin-channel`

把个人微信机器人接入本机 DeepSeek Harness：在微信里给机器人发消息，本机 DSH Agent 就会处理并回复。

## 术语

- **微信频道**：本插件中的一个微信接入单元，对应一个已登录的微信机器人。插件只允许存在 **一个** 微信频道。
- **微信用户**：扫码登录时使用的个人微信账号。添加频道不会创建新的微信账号，而是把本机生成的机器人绑定到当前扫码用户。

## 功能

- 使用手机微信扫码登录，登录态保存在本机，重启 DSH 无需重复扫码。
- 一个插件只承载一个微信频道：个人微信一个用户只能创建一个机器人。
- 首次安装后，主界面中央显示 **添加微信频道**；已有频道时不再显示添加入口，右上角显示 **设置**。
- 频道独立的模型、工作区、权限、Agent 预设、私聊准入、发送方式、命令权限。
- 文本、Markdown、图片、语音、文件、视频、审批卡片、提问卡片、延迟投递、斜杠命令。
- 微信会话在任务列表中显示微信品牌标；会话底部输入区替换为微信只读提示，并支持停止生成。

## 安装（本地开发）

### 方式 A：界面安装（推荐）

在 DSH 的「插件 → 添加插件」界面中输入：

```
@cubeai/dsh-weixin-channel
```

或：

```
https://openi.pcl.ac.cn/dsh/dsh-weixin-channel.git
```

安装后刷新 DSH 页面，左侧边栏会出现 **DSH微信频道** 菜单项。

### 方式 B：命令行安装（适用于 web profile）

```bash
dsh plugin --profile web add https://openi.pcl.ac.cn/dsh/dsh-weixin-channel.git
```

或从 npm 安装：

```bash
dsh plugin --profile web add @cubeai/dsh-weixin-channel
```

## 添加微信频道

1. 打开左侧边栏 **DSH微信频道**。
2. 点击主界面中央的 **添加微信频道**。
3. 填写频道名称，按需选择工作区、模型、权限等初始设置。
4. 点击 **生成二维码**，使用手机微信扫码并确认登录。
5. 登录成功后频道会直接显示在页面中；收到微信消息后，对话界面直接内嵌在频道页里（只有一个会话，无需再点进会话）。

已有频道时右上角显示 **设置**，可修改频道名称、工作区、模型、权限、Agent 预设、私聊准入、发送方式、命令权限，并可诊断连接、重新连接或删除频道。

> 个人微信一个用户只能创建一个机器人。若要更换微信账号，请先删除现有频道，再重新添加。
